# Pull Request Automation

Use this skill to systematically scrape code diffs and validation summaries to build a professional, compliant PR description block.

## Document Ingestion Metrics
- **Context Source:** `docs/requirements.md` (Scope mapping)
- **Review Ledger:** `docs/code-review.md` (Known mitigations/limitations)
- **Evidence Baseline:** `docs/verification-report.md` (Test execution passes)

## Output Format
This skill must generate its summary inside `docs/pull-request-desc.md` using this exact layout format:

```markdown
# Pull Request Description

## 📝 Summary
[2-3 sentence overview generated by Copilot explaining what was built and why, referencing the KAN ticket context].

## 🛠️ Changes Made
- **File Added/Modified:** `src/components/AssetList.ts` -> Added core validation to handle invalid asset extensions.
- **File Added/Modified:** `tests/AssetList.test.ts` -> Added unit tests covering the empty-array error handler.

## 🧪 Test Evidence
```text
